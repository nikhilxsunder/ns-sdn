Getting started#

ns-sdn is one model behind one pattern. NSSDN holds the series and the specification, fit() trains the network, and the NSSDNResult it returns is a frozen record of everything the fit is: the decomposition as arrays, the one-step fit and its residuals, the trained network behind a numpy interface, and a summary that states what the numbers assume. Learn the pattern once and the whole library reads the same way; readers of cultivars already know it.

The three pages below take about fifteen minutes in order. Readers who know the model from the papers can start at the quickstart; readers who want to know why the library is shaped the way it is can start at the concepts.
